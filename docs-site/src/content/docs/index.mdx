## One library, two kinds of item

<CardGrid>
  <Card title="Artifacts">
    Files and folders, uploaded by people or linked by agents through AgentPod. Versioned,
    secret-scanned on the way in, and shown in a sandboxed viewer on a separate origin.
  </Card>
  <Card title="Work records">
    SuperPipeline work history, one record per card, kept current by signed push events.
  </Card>
  <Card title="Outcomes">
    Every item says how it turned out: approved, completed, in-progress, superseded, rejected,
    failed or abandoned. Search ranks good work first and never hides the rest.
  </Card>
  <Card title="Four ways in">
    The web app, the `suli` command line, an MCP server with three read-only tools, and an HTTP
    API.
  </Card>
</CardGrid>

SuperLibrary runs on Cloudflare Workers and signs people in through the SuperJackfruit account
service. Start with [what it is](/what-it-is/), then [install `suli`](/install/).

For agents, the same docs are published as plain text: [`/llms.txt`](/llms.txt) indexes them, and
[`/llms-full.txt`](/llms-full.txt) is every page in one file.
